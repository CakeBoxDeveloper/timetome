# TTM Massage Bot

Telegram бот для студії масажу **Час для себе**.

## Функції
- ✅ Перевірка підписки на канал `@pro_telo_niko` при кожному зверненні
- 🎟 Перевірка коду знижки з лотереї

## Запуск

```bash
cd bot
npm install
cp .env.example .env
# Відредагуй .env — встав токен бота від @BotFather
node bot.js
```

## Управління кодами знижок

Коди зберігаються у файлі `codes.json`:

```json
{
  "TTM1A0BTEST": { "discount": "10%", "desc": "Знижка 10% на будь-який сеанс" }
}
```

**Щоб видалити використаний код** — просто видали рядок із `codes.json` та збережи файл.  
Бот підхоплює зміни без перезапуску (читає файл при кожній перевірці).

## Структура коду лотереї

Код генерується на сайті у форматі: `TTM` + день(hex) + місяць(hex) + контрольний символ + 5 випадкових символів.

Приклад: `TTM130AD7R5X6` = 19 жовтня.
